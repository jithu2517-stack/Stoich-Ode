Why Dataset Splits Diverge by O(Δt) While Conserving Mass
The benchmark splits use explicit Forward Euler (y_{n+1} = y_n + Δt·S·r(y_n)) at three step sizes (Δt = 0.5s, 1.0s, 2.0s). At t = 2.0s, local truncation error produces distinct concentrations, yet all three conserve mass to 2.000000g because 1ᵀ(y_n + Δt·S·r) = 1ᵀy_n + Δt(1ᵀS)r = 2.0g.

STEP 01 // SIMPLIFIED TWO-STAGE BASELINE APPROXIMATE
This console's M2 is a simplified, paper-inspired baseline: it first reduces mass-rate residuals, then fits the trajectory with a soft mass-residual term. It is not a faithful reproduction of Coelho et al.'s method.
# Simplified project baseline (paper-inspired, not a reproduction) p_adm = fit_to_reduce_mass_rate_residuals(p0) loss_II = trajectory_MSE(y_pred, y_true) + lambda_mass * mass_residual(y_pred) p_final = fit_trajectory(p_adm, loss_II)
STEP 02 // HARD STOICHIOMETRIC PROJECTION (M3) 1ᵀS = [0, 0]
Instead of penalizing violations post-hoc, M3 parameterizes the neural network in reaction flux space r_θ(y) ∈ ℝ₊² and projects through the exact stoichiometric matrix S whose columns lie in the orthogonal complement of 1 = [1, 1, 1, 1]ᵀ:
S = [[-1, 0], # dA/dt = -r1 [-1, +1], # dB/dt = -r1 + r2 [+1, -1], # dC/dt = +r1 - r2 [+1, 0]] # dD/dt = +r1 # Conservation Proof for ANY neural network r_theta(y): d/dt (A+B+C+D) = [1,1,1,1] @ S @ r_theta(y) = [0,0] @ r_theta(y) = 0
STEP 03 // SPARSE MECHANISTIC DISCOVERY (M4) DEMO MODEL
The Python benchmark maps finite-difference observations to empirical fluxes with r(t) = S⁺ Δy/Δt, then applies thresholded least squares to candidate features. This is a sparse fit; no ridge term is used:
Basis Phi(y) = [A*B, C, A*C, B*D] sequential_thresholded_least_squares( S_pinv @ dy_dt, Phi(y), threshold=1e-3 ): -> r1(y) = 0.1000 * [A][B] (Bimolecular A + B -> C + D) -> r2(y) = 0.0500 * [C] (Unimolecular regen C -> B) Equilibrium limit (t -> inf): [A]=0, [B]=1.0g, [C]=0, [D]=1.0g
